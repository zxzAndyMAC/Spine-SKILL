# Asset notes

## Project logo

`assets/logo.png` was generated specifically for this repository using the built-in image-generation tool. The [generation prompt](assets/logo-prompt.txt) is retained for reproducibility. It is an independent project emblem, not the official Spine logo. The repository's MIT license does not grant separate reuse rights to image files.

## Hog Rider showcase

`examples/hog-rider/run.gif` is a native Spine export of the user-approved v008 animation, made from AI-assisted artwork inspired by Supercell's *Clash Royale*. It was exported for this README at 40% scale without changing the animation: 553 × 484 pixels, 81 frames, 40 ms per frame, 3.24 seconds, looping. GIF transparency differs from runtime alpha blending.

This fan-art study demonstrates the workflow. It is excluded from the repository's MIT license and does not provide a license to reuse the character, game assets, trademarks, or animation commercially.
